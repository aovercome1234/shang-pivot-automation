# PRD 模板（版本级 · 产品自包含）

> 复制本模板到 `PRD-V<x.y>-<主题>.md` 后逐节填写。
> **写作要求**：
> 1. **自包含**：不引用技术设计文档（架构/数据库/接口）；读者只需本文即可理解产品。
> 2. **字段规则必写**：每个表单功能必须有输入规则表（字段 / 必填 / 规则 / 错误提示），规则含长度、字符类型、取值范围、唯一性。
> 3. **组件约束必写**：上传（类型/大小/数量/排序）、输入（即时校验）、步进器（边界）、日期选择（可选范围）等约束写在对应功能下。
> 4. **简单明了**：短句、表格优先；不写修饰性描述；一件事一句话说清楚。
> 5. 术语与业务状态沿用全站统一叫法，不自造同义词。
> 截图放本目录 `shots/`，以 PRD 文件为相对基准引用。

# 7. 功能需求总览
（FR 表：ID / 模块 / 功能 / 优先级 / 详设章节。FR 是追溯锚点。）

# 8. 功能与页面详设
（每个功能一节（8.1、8.2…），对齐 §7。**截图与规则写在同一节**，不要再拆「页面与交互」章。
每节顺序建议：
1. **页面截图**（有独立页时；多端则 Web∥H5 成对）
2. **输入规则表** / **业务规则** / **组件约束**
3. **交互**：操作顺序、确认弹窗、反馈、跳转
章首可写 8.0：原型索引 + 全局交互规范。
）
