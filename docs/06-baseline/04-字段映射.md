## 1. 三层转换规则（先读这节，后面所有表都按它读）

```text
数据库列名            Java 实体字段         接口 JSON 字段
snake_case     ⇄     camelCase      ⇄     camelCase（同名）
```

| 环节 | 规则 | 证据 |
|---|---|---|
| 列名 → 字段 | MyBatis-Plus `map-underscore-to-camel-case: true`，自动把 `snake_case` 映射成 `camelCase` | `backend/shang-server/src/main/resources/application.yaml:76-78` |
| 字段 → JSON | Jackson 直接用字段名，**不做任何改名** | `JacksonConfig.java`（只注册 Long 序列化器，无命名策略） |
| **`Long` → JSON 字符串** | 全局 `ToStringSerializer`：所有 `Long`/`long` **返回字符串**，不是数字 | `JacksonConfig.java:17-22`；实测 `'total':'3'`、`'customerId':'9001'` |
| `Integer` / `BigDecimal` / `Boolean` | 保持 number / boolean | 实测 `'quantity':49`、`'price':599.00` |
| 时间字段 | ISO-8601 **字符串**（带偏移，Asia/Shanghai，不转时间戳） | `application.yaml:39-45`；实测 `'2026-09-30T00:27:19.62973+08:00'` |
| JSONB 列 | 映射为 `List` / `Map`，在 JSON 里就是 array / object | 实体上的 `@TableField(typeHandler = JacksonTypeHandler.class)` |
| `null` 字段 | **整个键被省略**（不是 `null`） | `application.yaml:44`（`default-property-inclusion: non_null`） |
| 分页响应 | `PageResult` 包成 `{total, records}`；**`total` 是字符串**（Long） | `PageResult.java`；实测 `'total':'3'` |
| 逻辑删列 | `deleted` 是**实体字段**，会出现在 JSON 里（`false`） | `BaseEntity.java:23-24` |

> **写断言时的直接后果**：`total`、`id`、`*Id`、`soldCount`、`orderCount` 等 Long 字段一律按**字符串**比对；
> 按数字断言会假失败。缺字段可能只是 `null` 被省略——先判存在再取值。
