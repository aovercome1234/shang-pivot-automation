# SDD 模板（开发可读版）

复制为 `v<x.y>/开发设计.md`，并在同目录维护 `数据模型.md` / `接口设计.md`。

## 质量底线（不写就过不了评审）

| 文档 | 必须有 |
|---|---|
| **开发设计** | 范围、模块映射到类/服务、**主路径时序图或状态图**、事务/幂等/失败分支文字说明 |
| **数据模型** | 每张表：**字段 / 类型 / 可空 / 中文说明**；核心不变式；Flyway 版本 |
| **接口设计** | 统一响应约定；**关键接口**写清：方法路径、入参表、出参表、**请求 JSON 示例、响应 JSON 示例**、错误示例；其余可目录 + 链 OpenAPI |

禁止只贴一张「路径列表」或「字段类型无说明」冒充详设。

## 开发设计骨架

```markdown
# Vx.y 开发设计
## 1. 范围与结论
## 2. 架构与模块映射（Controller → Service → 表）
## 3. 关键实现方案（每条：目标 + mermaid + 要点表）
## 4. 链到 数据模型.md / 接口设计.md
## 5. 安全 / Job / 出口
## 变更记录
```
