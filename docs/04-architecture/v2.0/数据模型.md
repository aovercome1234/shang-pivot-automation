# 数据模型 — V2.0（增量）

| 项 | 内容 |
|---|---|
| 状态 | Draft（实现前） |
| 基座 | [`../v1.0/数据模型.md`](../v1.0/数据模型.md)（字段说明、不变式、Flyway V1～V7） |
| 总览 | [`开发设计.md`](./开发设计.md) |

> **禁止修改已应用的 V1～V7**。本版从 **Flyway V8** 起追加 DDL。
> 版本纪律：本文件只描述 V2.0 的表与字段；V3.0 起的新表在该版本文档中描述，本文不提前收录。  
> 下表「说明」列必须写清业务含义，开发建表/写 Entity 以本文 + 迁移脚本为准。

### 1 V1.0 已有、本版本复用

| Schema | 表 | V2.0 用法 |
|---|---|---|
| `identity` | `system_config` | 增交易类配置键（运费/关单分钟） |
| `identity` | `file_object` | C 端上传复用；`biz_type` 扩展 `AVATAR`/`AFTER_SALE`/`SITE_LOGO`/`HOME_BANNER` |
| `identity` | `dict` / `dict_item` | 补物流承运商字典 |
| `commerce` | `category`/`brand`/`attribute`/`spu`/`sku`/`stock`/`warehouse` | C 端只读上架；`spu` 增字段见 §3.2 |
| `commerce` | `order`/`order_item`/`payment`/`shipment`/`after_sale` | 真实顾客单；`order` 增字段见 §3.2 |
| `commerce` | `stock_log` | 发货/出入库继续写流水 |

**缺口（V1.0 设计有、库未建齐）**：`identity.customer`；`commerce` 的 `cart`/`cart_item`/`address`/`favorite`/`browse_history`/`review`；出入库单据表。本版本一并建表。

### 2 字段增量（ALTER）

| 表 | 字段 | 类型 | 说明 |
|---|---|---|---|
| `commerce.spu` | `sold_count` | `BIGINT NOT NULL DEFAULT 0` | 支付成功累加；列表「N 人付款」 |
| `commerce.spu` | `schedule_on_at` | `TIMESTAMPTZ NULL` | 定时上架；Job 扫描 |
| `commerce."order"` | `client_type` | `VARCHAR(16)` | `web`/`h5`/`mp`；列表筛选 |
| `commerce."order"` | `customer_phone_mask` | `VARCHAR(32)` | 下单时写入脱敏手机，便于后台按尾号筛 |

索引建议：`spu(schedule_on_at) WHERE schedule_on_at IS NOT NULL`；`order(client_type)`；`order(customer_id, created_at DESC)`。

### 3 新建表 — identity

#### `identity.customer`（顾客）

| 列 | 类型 | 约束/说明 |
|---|---|---|
| `id` | BIGINT PK | |
| `openid` | VARCHAR(64) | 微信；可空（V2.0 手机号登录）；唯一（非空） |
| `union_id` | VARCHAR(64) | 可选 |
| `phone` | VARCHAR(20) | 唯一（非空优先）；登录主键之一 |
| `nickname` | VARCHAR(64) | |
| `avatar` | VARCHAR(512) | MinIO objectKey 或 public URL |
| `gender` | SMALLINT | 0 未知 / 1 男 / 2 女 |
| `status` | VARCHAR(16) | `NORMAL` / `FROZEN`；冻结拒登拒下单 |
| `last_login_at` | TIMESTAMPTZ | |
| `created_at` / `updated_at` / `deleted` / `trace_id` | 同约定 | |

索引：`uk_customer_phone`、`uk_customer_openid`（WHERE NOT NULL）。

### 4 新建表 — commerce 交易侧

#### `commerce.cart` / `commerce.cart_item`

| 表 | 列 | 说明 |
|---|---|---|
| `cart` | id, `customer_id`(unq), created_at, updated_at | 一顾客一车 |
| `cart_item` | id, cart_id, sku_id, quantity, selected(bool), created_at, updated_at | uk(cart_id, sku_id) |

#### `commerce.address`

| 列 | 说明 |
|---|---|
| id, customer_id | |
| name, phone | 收件人 |
| province, city, district, detail | 省市区+详细 |
| is_default | bool；同顾客仅一条 true（应用层保证） |
| created_at, updated_at, deleted | |

#### `commerce.favorite` / `commerce.browse_history`

| 表 | 列 | 说明 |
|---|---|---|
| `favorite` | id, customer_id, spu_id, created_at | uk(customer_id, spu_id) |
| `browse_history` | id, customer_id, spu_id, last_at | uk(customer_id, spu_id)；浏览更新 last_at |

#### `commerce.review`

| 列 | 说明 |
|---|---|
| id, order_item_id(unq), customer_id, spu_id | 一订单项一评 |
| rating | 1～5 |
| content | text |
| pics | jsonb objectKey[] |
| status | `VISIBLE`（发表即可见）/ `HIDDEN`（后台隐藏） |
| created_at, updated_at, deleted, trace_id | |

> 本版评价「发表即展示」，不设待审状态：`status` 取 `VISIBLE`（展示）/ `HIDDEN`（后台隐藏）。C 端详情只出 `VISIBLE`。

#### `commerce.in_out_order` / `commerce.in_out_item`（出入库单据 A7）

| 表 | 列 | 说明 |
|---|---|---|
| `in_out_order` | id, bill_no(unq), type(`PURCHASE_IN`/`STOCKTAKE`/`SALE_OUT`), warehouse_id, operator_id, remark, related_order_no(可空), created_at, trace_id | 发货自动生成 `SALE_OUT` |
| `in_out_item` | id, bill_id, sku_id, qty(有符号：入正出负), remark | |

与 `stock` 变更同事务；并写 `stock_log`。

### 5 新建表 — 站点品牌与运营位（A10 / A10b）

#### `commerce.site_brand`（可单行）

| 列 | 说明 |
|---|---|
| id | 固定用 `1` 或业务键 |
| logo_key | MinIO objectKey（public） |
| name | 默认「尚品汇」 |
| slogan | 如「选好物，享生活」 |
| favicon_key | 可空 |
| updated_at, updated_by, trace_id | |

> 亦可落 `identity.system_config`（`site.logo` 等）；**推荐独立表**便于管理端表单与权限隔离。二选一，实现前定一种。

#### `commerce.home_slot` / `commerce.home_slot_item`

| 表 | 列 | 说明 |
|---|---|---|
| `home_slot` | id, code(unq), title, status(`ON`/`OFF`), sort, valid_from, valid_to, updated_at | code 见下表 |
| `home_slot_item` | id, slot_id, sort, spu_id(可空), image_key(可空), link_type(`SPU`/`CATEGORY`/`URL`/`NONE`), link_value(可空), title(可空), extra(jsonb), status | Banner 用图+链接；选品用 spu_id |

**预置 slot.code**

| code | 用途 |
|---|---|
| `home_banner` | 首页 Banner 轮播 |
| `home_promo_subsidy` | 活动位 · 热门精选（选品） |
| `home_promo_flash` | 活动位 · 新品上架（选品） |
| `home_promo_live` | 活动位 · 品牌专区（选品） |
| `home_hot_keywords` | 热搜词（item.title=词；link 可空） |
| `home_hot_spus` | 热门精选 SPU |

C 端过滤：`slot.status=ON` 且在时间窗内；item 绑定的 SPU 须 `spu.status=ON`，否则丢弃。

### 6 系统配置键（写入 `identity.system_config`）

| config_key | category | 默认 | 说明 |
|---|---|---|---|
| `order.pay-timeout-minutes` | TRADE | `15` | 待付款超时关单 |
