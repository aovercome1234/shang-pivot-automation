# 接口设计 — V2.0（增量）

| 项 | 内容 |
|---|---|
| 状态 | Draft（实现前） |
| 基座约定 | [`../v1.0/接口设计.md`](../v1.0/接口设计.md)（Admin） |
| 总览 | [`开发设计.md`](./开发设计.md) |

> 本版新增 **顾客端** `/api/**` 与后台运营补丁；Admin 既有接口仍见 V1。  
> 统一响应 `{ code, msg, data, traceId }`，规范同 [`../v1.0/接口设计.md`](../v1.0/接口设计.md) §1。  
> C 端前缀 **`/api`**；后台 **`/admin`**。顾客 JWT：`clientType ∈ {web,h5}`。  
> Long 型 id **字符串**输出。写接口建议带 `Idempotency-Key` / `idempotentKey`（下单/支付/取消）。

---

## 0. 关键接口详细示例（实现契约）

### 0.1 发送验证码 / 登录

`POST /api/auth/sms/send`（可匿名）

```json
// request
{ "phone": "13800138000" }
// response data
{ "cooldownSec": 60 }
```

`POST /api/auth/login`（可匿名；路径以实现为准，亦可 `/api/auth/phone`）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| phone | string | 是 | 11 位手机号 |
| code | string | 是 | 6 位验证码（演示可固定 `123456`） |
| clientType | string | 是 | `web` / `h5` |

```json
// request
{ "phone": "13800138000", "code": "123456", "clientType": "h5" }
// response data
{
  "accessToken": "eyJ...",
  "refreshToken": "eyJ...",
  "expiresIn": 7200,
  "customer": {
    "id": "9001",
    "phone": "138****8000",
    "nickname": "用户8000",
    "avatar": null,
    "status": "NORMAL"
  }
}
```

冻结：`{ "code": 40310, "msg": "账号不可用", "data": null }`

### 0.2 加购

`POST /api/cart/items`（需顾客 JWT）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| skuId | string | 是 | SKU ID |
| quantity | number | 是 | ≥1；不得超过可售 |

```json
// request
{ "skuId": "1001", "quantity": 2 }
// response data
{ "cartItemId": "5001", "quantity": 2, "selected": true }
```

库存不足：`{ "code": 40901, "msg": "库存不足", "data": null }`

### 0.3 提交订单

`POST /api/orders`（需 JWT）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| addressId | string | 是 | 收货地址 |
| cartItemIds | string[] | 二选一 | 购物车结算 |
| skuId + quantity | — | 二选一 | 立即购买 |
| idempotentKey | string | 是 | 客户端生成 UUID，防重复单 |

```json
// request
{
  "addressId": "3001",
  "cartItemIds": ["5001"],
  "idempotentKey": "8f1e2d3c-4b5a-6789-abcd-ef0123456789"
}
// response data
{
  "orderId": "8001",
  "orderNo": "O202609191200001",
  "status": "PENDING_PAY",
  "goodsAmount": 17998.00,
  "freight": 0,
  "payAmount": 17998.00,
  "expireAt": "2026-09-19T12:15:00+08:00"
}
```

### 0.4 沙箱支付

`POST /api/payment/sandbox`

```json
// request
{ "orderId": "8001" }
// response data（成功）
{
  "orderId": "8001",
  "status": "PENDING_SHIP",
  "paidAt": "2026-09-19T12:01:02+08:00",
  "tradeNo": "SANDBOX-8001"
}
```

### 0.5 后台冻结会员

`PUT /admin/customers/{id}/status`

```json
// request
{ "status": "FROZEN" }
// response
{ "code": 0, "msg": "ok", "data": null }
```

> 下列为资源一览；字段细节以本节示例 + OpenAPI（实现后）为准。

### 1 鉴权约定

| 前缀 | 鉴权 | 说明 |
|---|---|---|
| `/api/auth/**`、`GET /api/home`、`GET /api/site/brand`、`GET /api/products*`、`GET /api/categories`、`GET /api/search` | 可匿名 | 游客浏览 |
| 其余 `/api/**` | 顾客 JWT | 冻结顾客 → 401/业务码拒绝 |
| `/admin/**` | 后台 JWT + `@PreAuthorize` | 权限码见 §8 |

### 2 C 端 — 认证与资料（identity）

| 方法 | 路径 | 请求 | 响应 data | 说明 |
|---|---|---|---|---|
| POST | `/api/auth/phone` | `{ phone, code, clientType }` | `{ accessToken, refreshToken, expiresIn, customer }` | 验证码 mock（如 `123456`）；查/建 Customer |
| POST | `/api/auth/refresh` | `{ refreshToken }` | 同登录 token 对 | Refresh 轮转 |
| POST | `/api/auth/logout` | — | null | 吊销 jti |
| GET | `/api/me` | — | `{ id, phone, nickname, avatar, status }` | |
| PUT | `/api/me` | `{ nickname?, avatar? }` | 更新后资料 | 头像 objectKey 先走上传 |

错误：验证码错 `40101`；冻结 `40310`；clientType 非法 `40000`。

### 3 C 端 — 首页 / 品牌 / 商品

| 方法 | 路径 | 查询/体 | 响应 data | 说明 |
|---|---|---|---|---|
| GET | `/api/site/brand` | — | `{ logoUrl, name, slogan, faviconUrl? }` | 可短缓存 |
| GET | `/api/home` | `feedSize?`(默认 20) | 见下方 **HomeVO** | 首屏聚合 |
| GET | `/api/categories` | — | 树 `[{ id, name, children }]` | 仅启用 |
| GET | `/api/products` | `categoryId?, page, size, sort=comp\|sold\|price_asc\|price_desc` | `{ total, records: ProductCard[] }` | 仅 `ON` |
| GET | `/api/products/{spuId}` | — | **ProductDetailVO** | 下架 → 404 |
| GET | `/api/search` | `q, page, size` | 同列表 | 名称/副标题；空 q 返回空列表 |

**HomeVO**

```json
{
  "brand": { "logoUrl": "", "name": "尚品汇", "slogan": "选好物，享生活" },
  "slots": [
    {
      "code": "home_banner",
      "title": "首页 Banner",
      "items": [
        { "imageUrl": "", "linkType": "SPU", "linkValue": "10001", "title": "" }
      ]
    },
    {
      "code": "home_hot_spus",
      "title": "热门活动",
      "items": [
        { "spuId": "10001", "name": "", "pic": "", "price": 299, "soldCount": 700 }
      ]
    }
  ],
  "feed": [ /* ProductCard，运营位不足时按 home.feed-sort 补位 */ ]
}
```

**ProductCard**：`{ spuId, name, subtitle?, pic, price, priceMax?, soldCount }`  
**ProductDetailVO**：SPU 信息 + `skus: [{ skuId, title, price, specs, pic, availableStock }]` + `reviewsPreview` + `soldCount`。

### 4 C 端 — 购物车

| 方法 | 路径 | 请求 | 说明 |
|---|---|---|---|
| GET | `/api/cart` | — | `{ items: CartItemVO[], selectedAmount, available }`；含失效标记 |
| POST | `/api/cart/items` | `{ skuId, quantity }` | 合并同 SKU；校验可售 |
| PUT | `/api/cart/items/{id}` | `{ quantity?, selected? }` | 超库存拒绝 `40901` |
| DELETE | `/api/cart/items/{id}` | — | |
| POST | `/api/cart/clear-invalid` | — | 清理下架/无库存项 |

**CartItemVO**：`{ id, skuId, spuId, title, pic, specsText, price, quantity, selected, valid, invalidReason? }`。

### 5 C 端 — 地址 / 收藏 / 足迹

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/addresses` | 列表 / 新增 |
| PUT/DELETE | `/api/addresses/{id}` | 改 / 删 |
| PUT | `/api/addresses/{id}/default` | 设默认 |
| GET | `/api/favorites` | 分页收藏 SPU 卡片 |
| POST/DELETE | `/api/favorites/{spuId}` | 收藏 / 取消 |
| GET | `/api/history` | 足迹，按 `last_at` 倒序 |
| DELETE | `/api/history` | 清空 |

### 6 C 端 — 订单 / 支付 / 物流

| 方法 | 路径 | 请求 | 说明 |
|---|---|---|---|
| POST | `/api/orders` | `{ addressId, cartItemIds[], idempotentKey }` 或 `{ skuId, quantity, addressId }` | 锁库存；算运费；写 `client_type`/`phone_mask`；清已购车项；→ 待付款 |
| GET | `/api/orders` | `status?, page, size` | 当前顾客 |
| GET | `/api/orders/{id}` | — | 含 items、payment、shipment、timeline |
| POST | `/api/orders/{id}/cancel` | — | 仅待付款；释锁 |
| POST | `/api/orders/{id}/confirm` | — | 仅待收货 → 已完成 |
| POST | `/api/payment/sandbox` | `{ orderId }` | 沙箱成功 → 待发货；`sold_count += qty` |
| GET | `/api/payment/{orderId}/status` | — | 支付状态 |
| GET | `/api/orders/{id}/logistics` | — | `Shipment` 轨迹 |

**金额**：`payAmount = goodsAmount + freight`（V2.0 无券）；`freight = goodsAmount >= freeThreshold ? 0 : defaultAmount`。

### 7 C 端 — 售后 / 评价 / 文件

| 方法 | 路径 | 请求 | 说明 |
|---|---|---|---|
| POST | `/api/after-sales` | `{ orderId, type, reason, evidenceKeys[], refundAmount? }` | 待收货/已完成可申请 |
| GET | `/api/after-sales` | `status?, page, size` | |
| GET | `/api/after-sales/{id}` | — | |
| POST | `/api/reviews` | `{ orderItemId, rating, content, picKeys[] }` | 已完成；发表即 `VISIBLE` |
| GET | `/api/products/{spuId}/reviews` | `page, size` | 仅 `VISIBLE` |
| POST | `/api/files/presign` | `{ bizType, contentType, sizeBytes }` | 返回 `{ uploadUrl, objectKey, publicUrl? }` |
| POST | `/api/files/confirm` | `{ objectKey, bizType }` | 写 `file_object`，uploader=customerId |

`bizType`：`AVATAR`（public）/ `AFTER_SALE`（private）/ 其他按策略。禁止调用 `/admin/files/*`。

### 8 管理端 — 会员 / 内容 / 评价（V2.0 新增）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/admin/customers` | `customer:list` | 查询：`phone`/`nickname`/`status`/`page`/`size`；手机脱敏 |
| GET | `/admin/customers/{id}` | `customer:list` | 详情 + `orderCount` |
| PUT | `/admin/customers/{id}/status` | `customer:freeze` | `{ status: NORMAL\|FROZEN }`；写操作日志 |
| GET/PUT | `/admin/site/brand` | `content:brand` | 读/写 Logo、name、slogan |
| GET | `/admin/home/slots` | `content:home` | 全部槽位摘要 |
| GET/PUT | `/admin/home/slots/{code}` | `content:home` | 读写槽位 + items（排序、启停、时间窗） |
| GET | `/admin/reviews` | `review:list` | 筛选星级/可见性/关键字 |
| PUT | `/admin/reviews/{id}/status` | `review:hide` | `{ status: VISIBLE\|HIDDEN }` |

### 9 管理端 — 交易增强 / 出入库 / 配置

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/admin/orders` | `order:list` | **增** `phoneTail`、`clientType` 筛选；返回字段含二者与支付摘要 |
| GET | `/admin/orders/{id}` | `order:list` | **增** `tradeNo`、`paidAt`、`clientType`、脱敏手机 |
| GET | `/admin/orders/export` | `order:export` | 当前筛选 → CSV/xlsx 流 |
| POST | `/admin/orders/{id}/ship` | `order:ship` | 既有；**同事务**写 `SALE_OUT` 出入库 + stock 出库 |
| GET | `/admin/in-out` | `stock:io` | 出入库分页；`type` Tab |
| POST | `/admin/in-out` | `stock:io` | `{ type, warehouseId, items[{skuId,qty}], remark }`；采购入/盘点 |
| GET/PUT | `/admin/system-configs` | 既有 | category=`TRADE` 读写超时/运费/补位排序 |
| PUT | `/admin/products/{id}` | `product:edit` | body 可含 `scheduleOnAt`；定时上架 Job 消费 |

### 10 内部 Job（非 HTTP）

| Job | Cron | 逻辑 |
|---|---|---|
| `PayTimeoutCloseJob` | 每分钟 | `status=PENDING_PAY AND created_at < now()-N` → 关单 → `locked-=qty` → 幂等 |
| `ScheduleOnShelfJob` | 每分钟 | `schedule_on_at<=now` 且草稿/下架 → 校验上架规则 → `ON`，清空 schedule |

### 11 错误码（V2.0 增量）

| code | 含义 |
|---|---|
| `40310` | 顾客已冻结 |
| `40901` | 库存不足 |
| `40902` | 订单状态不允许 |
| `40903` | 运营位绑定的 SPU 已下架（管理端保存时可警告） |
| `40904` | 评价已存在（同 orderItem） |
| `40410` | 商品不存在或未上架 |
