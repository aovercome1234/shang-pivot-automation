# 数据模型 — V1.0（As-built）

> **脚本权威**：`backend/shang-server/src/main/resources/db/migration/V1__init.sql` + `V2`～`V7`。  
> 字段说明来自库内 `COMMENT ON COLUMN`；已应用迁移**禁止改内容**，后续版本增量从 V8 起。

## 1. 约定

| 项 | 说明 |
|---|---|
| Schema | `identity`（认证权限）· `commerce`（商品交易） |
| 主键 | `BIGINT` 雪花 ID；接口 JSON 建议当**字符串**处理，避免 JS 精度丢失 |
| 时间 | `TIMESTAMPTZ`；业务展示统一东八区 |
| 软删 | 多数表 `deleted`；查询默认过滤 |
| 媒体 | 存 objectKey / URL，不存服务器本地路径 |
| 追踪 | 可选 `trace_id` 关联请求 |

## 2. ER 关系

```text
identity.admin_user ──< admin_role >── role ──< role_permission >── permission
admin_user ──► dept
dict ──< dict_item
system_config · file_object · operation_log

commerce.category ──< attribute
commerce.category ◄── brand.category_id（V7）
category / brand ◄── spu ──< sku
sku × warehouse ── stock ──< stock_log
order ──< order_item
order ── payment / shipment / after_sale
```

## 3. 核心不变式：库存

```text
physical_stock ≥ locked_stock ≥ 0
可售 available = physical_stock − locked_stock   （不落库，查询时计算）
```

| 动作 | physical | locked | 本版是否可触发 |
|---|---|---|---|
| 手工调整（库存调整） | ±Δ | 不变 | ✅ 是 |
| 锁定占用（下单锁库） | 不变 | +qty | ❌ 否（V1 的锁定值来自演示种子，锁库动作由后续版本引入） |
| 发货出库 | −qty | −qty | ✅ 是 |
| 释放锁定（取消/超时） | 不变 | −qty | ❌ 否（同上） |

破坏不变式 → 业务拒绝（HTTP/业务码冲突类）。

## 5. 状态枚举（字符串）

| 对象 | 字段 | 取值 | 含义 |
|---|---|---|---|
| 账号/角色等 | status | `ENABLED` / `DISABLED` | 启用 / 禁用 |
| SPU | status | `DRAFT` / `ON` / `OFF` | 草稿 / 上架 / 下架 |
| SKU | status | `ENABLED` / `DISABLED` | 可售 / 停用 |
| 订单 | status | `PENDING_PAY` / `PENDING_SHIP` / `PENDING_RECEIVE` / `COMPLETED` / `CLOSED` | 待付/待发/待收/完成/关闭 |
| 售后 | status | `PENDING_AUDIT` / `REFUNDING` / `COMPLETED` / `REJECTED` | 待审/退款中/完成/拒绝 |
| 售后 | type | `REFUND` / `RETURN` | 仅退款 / 退货退款 |
| 权限 | type | `DIR` / `MENU` / `BUTTON` / `API` | 目录/菜单/按钮/接口 |
| 库存流水 | type | `INIT` / `ADJUST` / `SHIP` / … | 初始化/调整/发货等 |
