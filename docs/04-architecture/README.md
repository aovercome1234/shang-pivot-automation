# 04-architecture

| 层级 | 路径 | 写什么 |
|---|---|---|
| 决策 | [`adr/`](./adr/) | 长期成立的技术决策（ADR） |
| 版本设计 | [`v1.0/`](./v1.0/) · [`v2.0/`](./v2.0/) | 该版怎么实现 |
| 模板 | [`_template-SDD.md`](./_template-SDD.md) | 新版本复制骨架 |

## 每个版本三件套（统一）

```text
v<x.y>/
├── 开发设计.md   # 范围、架构增量、主流程 → 链到下面两份
├── 数据模型.md   # 表 / 字段 / 不变式 / Flyway
└── 接口设计.md   # 约定、资源目录、关键语义
```

| 版本 | 状态 |
|---|---|
| V1.0 | As-built（对齐 Flyway V1～V7 + 现有 Controllers） |
| V2.0 | Draft（实现前增量；Flyway 从 V8 起） |

**不要**：在开发设计里再贴一份完整字段表/接口表（避免三处漂移）。  
**必须**：开发设计有实现逻辑图；数据模型字段有中文说明；接口有入参/出参与示例（见 `_template-SDD.md` 质量底线）。  
**权威**：已落地脚本与 OpenAPI > 文档摘要；文档负责可读与评审。
