# ADR-0002：技术栈选型（Spring Boot 4 + PostgreSQL/pgvector + MyBatis-Plus + MinIO）

- **状态**：Accepted
- **日期**：2026-09-12（2026-09-13 补充对象存储）
- **决策范围**：跨版本基座
- **相关**：`ADR-0001`、`docs/04-architecture/v1.0/数据模型.md`、`docs/04-architecture/v1.0/接口设计.md`、`docs/00-product/roadmap.md`

## 背景（Context）

开发设计阶段需定技术栈。V3.0 智能客服需要 **RAG 向量检索**（数据库选型的硬约束）；商品图/凭证/知识库附件需要 **对象存储**，不宜落应用本地磁盘。

## 决策（Decision）

| 领域 | 技术 | 理由 |
|---|---|---|
| 运行时 | Java 21 / Maven 3.9 | 项目基础 |
| 框架 | Spring Boot 4.x | 当前主框架 |
| 入口（可选） | Spring Cloud Gateway | **可选**统一入口（路由/限流/traceId）；**不验签**（见 ADR-0003）。V1 As-built **未部署**，直连 `shang-server` |
| 数据库 | PostgreSQL 16 + pgvector | RAG 原生；JSONB/复杂查询；避免 V3 再迁库 |
| ORM | MyBatis-Plus | CRUD + 分页 + 可控 SQL |
| 缓存 | Redis 7 | 字典/权限缓存、登录锁定、JWT 黑名单、幂等 |
| 迁移 | Flyway | Schema 版本化 |
| 对象存储 | MinIO（S3 API） | 本地 Compose；生产可换云 OSS |
| API 文档 | Springdoc + Knife4j | `/v3/api-docs`、`/swagger-ui.html` |
| 日志 | Logback + MDC `traceId` | 响应 / 日志 / 审计同源 |
| AI | 第三方 LLM API + RAG | V3.0；本阶段预留 |
| 管理端前端 | Vue3 + Vite + TS + Element Plus + Pinia | 已定 |
| 购物端 | uni-app（规划） | V2.0 |
| 部署 | Docker Compose | postgres / redis / minio / app |
| 工具库 | Hutool | 降低样板代码 |

### 对象存储硬约束

1. 禁止业务文件持久化到应用本地磁盘（临时中转除外）。
2. DB 只存 objectKey（或稳定 URL），不存二进制。
3. 上传优先预签名 PUT；小文件可走后端代理。
4. 生产换云 OSS：只改 endpoint/凭证/bucket。

## 后果（Consequences）

**正面**：pgvector 免另引向量库；MinIO 与生产 S3 路径一致；MP 适合后台 CRUD。  
**风险**：团队需熟悉 Postgres 方言；MinIO 需纳入 Compose 运维。  
**回退**：MP 不兼容时可切 JPA；坚持 MySQL 则 V3 需另接向量库。
