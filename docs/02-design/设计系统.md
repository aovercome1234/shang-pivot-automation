## 3. 组件一眼记

- **主按钮**：琥珀底 + 墨字；点下去轻微下沉
- **次按钮**：白底描边；悬停偏珊瑚
- **表格**：表头浅沙色；金额右对齐用等宽字体
- **侧栏激活**：左边一条暖琥珀竖线
- **列表加载**：骨架屏，不要狂转圈
- **空状态**：图 +「去新增 / 去逛逛」，不要只写 No data
- **图标**：单色描边 SVG，`stroke-width: 2`，**不用 emoji 当图标**

## 4. 弹窗与反馈（全站统一，两版共用）

弹窗是最容易做歪的地方，这里定死。完整样例见 `docs/01-requirements/shots/dialogs.png`（后台 V1，53 例）、`p2-dialogs.png`（后台 V2 增量，18 例）、`store-web-dialogs.png` / `store-h5-dialogs.png`（C 端）。

### 4.1 形态

| 类型 | 用途 | 后台（Element Plus） | C 端 Web | C 端 H5 |
|---|---|---|---|---|
| 确认 | 可逆但需确认 | `ElMessageBox.confirm` | 居中对话框 | `showConfirmDialog` |
| 危险确认 | 删除 / 下架 / 冻结 | `ElMessageBox.confirm`（danger） | 居中对话框 | `showConfirmDialog` |
| 表单 | 新增 / 编辑 / 发货 / 审核 | `ElDialog` | 居中对话框 | 底部半屏 |
| 输入 | 重置密码 / 改密钥 | `ElMessageBox.prompt` | 居中对话框 | 底部半屏 |
| 拒绝提示 | 状态不允许 / 被引用 / 校验不过 | `ElMessageBox.alert` | 居中对话框 | `showDialog` |
| 抽屉 | 订单 / 售后 / 日志详情 | `ElDrawer` | 右侧抽屉 | 全屏 / 半屏 |
| 轻提示 | 成功 / 失败 / 警告 | `ElMessage` | Toast | `showToast` |

### 4.2 硬规则

1. **破坏性操作按钮用砖红**，且确认文案必须包含对象名称（「确认删除草稿『iPhone 15 Pro Max 256G』？」）。
2. **拒绝类弹窗只有一个「知道了」**，不给「取消」—— 否则用户会以为重试就能过。
3. **字段级校验错误内联**在控件下方，弹窗**不关闭**；跨字段业务校验在弹窗内**逐条列出**。
4. **弹窗内不嵌套弹窗**；需要连续两步时先关再开（如「改敏感值 → 保存确认」）。
5. 遮罩点击与 ESC 可关闭；纯提示类也允许。唯一例外是正在进行的支付/提交过程。
6. 提交类按钮进入 loading 并禁用，防重复提交。
7. 弹窗宽度分档：`is-sm` 380（纯提示）、`is-md` 440（确认/输入）、`is-lg` 620（表单）、`is-xl` 820（表格类选品）。
8. 危险操作的后果写在弹窗正文里（「发货后订单进入待收货，并扣减库存，此操作不可撤销」），不要只写「确定吗？」。

### 4.3 实现落点（后台）

| 用途 | 组件 |
|---|---|
| 表单 / 确认 | `shang-admin-web/src/components/FormDialog.vue` |
| 拒绝 / 提示 | `shang-admin-web/src/components/NoticeDialog.vue` |
| 详情抽屉 | `shang-admin-web/src/components/DetailDrawer.vue` |
| 样式 | `shang-admin-web/src/assets/modal.css` |

禁止再使用命令式弹窗（`ElMessageBox.prompt/alert`）与行内布局样式；Element Plus 必须挂 `zh-cn` locale，否则按钮会显示成 Cancel。

## 5. 明确不要做的（反套路）

紫/蓝渐变、霓虹光、Inter 默认脸、三列等宽「特性卡片」、居中假大空 Hero、emoji 堆砌、用砖红当价格色、用紫色当分类色。
