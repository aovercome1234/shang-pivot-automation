## 1. 通用约定

| 项 | 说明 |
|---|---|
| 管理端前缀 | `/admin/**`（除 `/admin/auth/login`、`/admin/auth/refresh` 外均需管理员 token） |
| C 端前缀 | `/api/**`（`/api/auth/**` 与少量 GET 浏览接口免认证） |
| 鉴权 | `Authorization: Bearer <access token>`；JWT 双令牌，access 900s / refresh 604800s |
| 成功信封 | `{"code":0,"msg":"success","data":{...},"traceId":"..."}`，**成功业务码为 0** |
| 失败信封 | `{"code":<错误码数值>,"msg":"<中文提示>","traceId":"..."}`，错误码词条见《领域词典.md》§9 |
| 分页 | MyBatis-Plus 分页，列表接口通用 `page`（从 1 起）/`size` 参数 |
| 删除 | 逻辑删（`deleted` 标记） |
| 免认证白名单（源码 SecurityConfig） | `/admin/auth/login`、`/admin/auth/refresh`、`/api/auth/**`、`/doc.html`、`/knife4j/**`、`/webjars/**`、`/v3/api-docs/**`、`/swagger-ui/**`、`/swagger-ui.html`、`/favicon.ico`、`/error` |
| 免认证 GET 白名单 | `/admin/files/view`、`/api/files/view`、`/api/home`、`/api/site/brand`、`/api/products`、`/api/products/**`、`/api/categories`、`/api/search` |
