业务规则（原型已体现）

  • 游客可浏览首页 / 分类 / 详情 / 搜索；加购、下单、个人中心需登录，登录后回到原场景。
  • 登录：手机号 11 位、验证码 6 位（演示固定 123456）、发送后 60 秒防重发；未注册手机号自动注册。
  • 库存 0 → 详情按钮变「暂时缺货」不可点；未选规格 → 「请选择规格」；超可售库存 → 「库存不足」并停在最大可售。
  • 运费：商品金额 ≥ ¥99 免运费，否则 ¥8（后台可配）。
  • 待付款 15 分钟倒计时（mm:ss），超时自动关闭并释放库存；待收货可确认收货；已完成可评价 / 售后 / 再次购买。
  • 后台补全页在 ../admin/（会员、站点品牌、首页运营位、交易设置、出入库单等）。
